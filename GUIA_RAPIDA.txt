🔧 SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════

❌ Error: "node no se reconoce"
   → Node.js no está instalado o no está en el PATH
   → Ejecuta: INSTALAR_NODEJS.bat
   → O instala manualmente desde nodejs.org

❌ Error: "Puerto 5173 ocupado"
   → Otro servidor está corriendo
   → Cierra todas las ventanas de terminal
   → Vuelve a ejecutar: INICIAR_PROYECTO.bat

❌ Error al instalar dependencias
   → Elimina la carpeta "node_modules"
   → Ejecuta nuevamente: INICIAR_PROYECTO.bat

❌ Cambios no se ven
   → Guarda el archivo
   → El servidor recargará automáticamente
   → Si no funciona, presiona Ctrl+C y reinicia
